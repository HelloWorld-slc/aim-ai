# Operators · 运算符

AIM AI 整理，2026-09-20。中文速查与接口索引；完整参数和示例见[官方文档](https://api.vex.com/aim/home/python/Logic/Operators.html)。

| 分组 | 索引 |
| --- | --- |
| 算术 | `+`、`-`、`*`、`/`、`//`、`%`、`**` |
| 增量赋值 | `+=`、`-=`、`*=`、`/=`、`//=`、`%=`、`**=` |
| 比较 | `==`、`!=`、`<`、`<=`、`>`、`>=`，支持连续比较 |
| 逻辑 | `and`、`or`、`not` |
| 对象身份 | `is`、`is not` |
| 成员 | `in`、`not in` |
| 序列 | 索引 `items[i]`、切片 `items[start:stop:step]`、拼接、重复、元素赋值、del |
| 字典 | 按键读取 / 赋值 / del、成员判断 |
| 字符串 | 拼接、重复、`%` 格式化 |
| 位运算 | `&`、`|`、`^`、`~`、`<<`、`>>` 及对应增量赋值 |

数值相等用 ==；is 用于对象身份，通常用 `value is None` 判断空值。`and` / `or` 会短路，且不一定返回 bool。用括号表达优先级。

`//` 向下取整，带浮点操作数时结果不保证是 int。切片右端不包含；字典读取不存在的键可能报错。角度环绕可用 `(target - current + 180) % 360 - 180`。
