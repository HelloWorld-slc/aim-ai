# 足球课堂与测试方法

AIM AI 原创教学建议，2026-09-20。

课程：5 次课，每次 90 分钟；2 名学生一台机器人，每人一台电脑。
进度：有限距离运动 → 识球与跟随 → 单机射门 → 双机分工 → 2v2 测试与复盘。
两人轮换任务描述/编程和实测记录角色；每组一台电脑负责最终下载。两个小组合并为双机队伍。

测试记录四项：预期行为、实际现象、发生条件、本次修改。每次只改一个主要因素，保留能运行的版本。
语法通过不能证明运动正确。电脑上的逻辑测试也不能替代场地、光照、轮子和通信的实际测试。
发现失败先缩小问题：看不到球、转向错误、动作阻塞、持球判断、通信超时分别验证。

正式赛事的 AI 使用、现场编程、场控和成人帮助边界，以对应赛季规则和主办方解释为准。
