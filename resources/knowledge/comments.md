单行注释使用 #，也可放在代码右侧。说明动作目的、单位和等待条件比复述代码更有价值。

```python
# 边长单位是毫米；先用低速测量实际轨迹
side_mm = 100
```

三引号会创建字符串；放在函数或模块开头可作为文档字符串，并非所有位置都等同于注释。多行说明可以逐行以 # 开头。

保留官方生成配置区标记；它们虽是注释，却可能被编辑器识别。不要通过大段注释掩盖未解决的控制逻辑。
